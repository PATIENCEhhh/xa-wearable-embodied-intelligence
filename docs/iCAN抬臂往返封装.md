# iCAN 抬臂往返模块

## 当前交付范围

已实现 M33 抬臂往返规划和执行会话接口，复用原工程 `rehab_scurve` 的 S 曲线。模块通过主机离线测试及当前 M33 工程构建检查。LVGL已加入动作选择与未就绪提示；尚未接入现有 CAN 控制所有者或 Wi-Fi 抬臂动作菜单，也未烧录或完成实物抬臂验收。

## LVGL接入状态

`firmware/m55/applications/ican_curl_panel.c` 已提供“屈肘往返 / 抬臂往返”选择、动作说明、启动、停止、状态及完成次数。运行中或等待命令确认时禁止切换动作。停止保持可点击，离开页面沿用停止与心跳失效退出机制。

选择抬臂时显示“4号抬臂往返 5、6号保持”和“抬臂未就绪 请先标定”，启动禁用，事件回调再次拦截。M33对共享邮箱的抬臂命令3明确返回 `ICAN_UI_LIFT_NOT_READY=-1001`，不会降级执行屈肘，也不改变现有运动状态。公共邮箱布局保持64字节。

这属于界面入口及未就绪状态的接入，不代表抬臂运动执行链路已经打通。实测端点并完成CAN适配后，才可解除门禁、发布抬臂命令并验收运行状态。

本次 M33、M55 均编译通过，跨核邮箱地址与ABI校验通过，中文字形覆盖检查通过，控制回归测试及抬臂离线测试通过。新增测试确认未标定的抬臂命令不会使能电机或误执行屈肘。界面尚未在实物屏幕验收，本次没有烧录。

4号电机的当前抬起端点和可用范围尚未实测。仅有初始位置不能代替行程标定，不使用原工程失效的其他关节目标或仿真参数作为实物目标。

## 动作顺序

1. 驱动适配层独占控制权，完成三轴参数预置、读回及运行反馈确认。
2. 捕获4、5、6号电机本次启动的位置。
3. 4号按 S 曲线到达已标定的抬起端点，5、6号保持本次启动位置。
4. 连续收到足够的新反馈确认到位，停留指定时间。
5. 4号返回本次启动位置，确认到位并停留。
6. 单次模式结束并停止三轴；循环模式再次抬起，直到收到停止请求或发生异常。

返回点为每轮会话启动时采集的真实位置。循环内保持该返回点，不逐轮累积漂移。STOP为撤销驱动的停止命令，不能视为保持力矩或实物已静止；机构需要机械支撑。

## 代码入口

- `firmware/m33/applications/control/rehab_arm_lift.h`：配置、状态、反馈和执行适配接口。
- `firmware/m33/applications/control/rehab_arm_lift.c`：轨迹、往返状态机、反馈检查、执行会话和停止重试。
- `tools/test/arm_lift_test.c`：实际C模块的仿真验收。
- `tools/test_arm_lift.py`：使用主机GCC构建并运行上述验收，不访问硬件。

规划接口 `rehab_arm_lift_start/step` 输出目标；执行接口 `rehab_arm_lift_session_start/step` 通过适配器发布目标。结构体首次使用前必须清零，由同一个控制线程串行访问。

执行适配器包含四个回调：

| 回调 | 责任 |
| --- | --- |
| `prepare` | 非阻塞准备，0表示等待，1表示成功，负值表示失败；适配层负责与现有控制所有者互斥，三轴停用时预置当前位置、模式、限流和限速并读回，再使能并检查运行反馈 |
| `feedback` | 返回三轴真实反馈和接收时间戳，不用调用时刻伪造新反馈 |
| `target_raw` | 通过现有唯一 CAN 出口写入指定电机的原始位置目标 |
| `stop` | 通过同一控制出口发送指定电机的 STOP，返回发送结果 |

目标按5号、6号、4号的顺序发布；任一发送失败不再发布后续目标，并转入整组三轴STOP。准备阶段最长10秒；STOP每轴最多尝试3次，间隔50毫秒，某一轴失败仍会尝试停止其他轴。发送成功不等于收到停止反馈或确认机械静止。

## 坐标及配置

`min_raw`、`max_raw`、`raised_raw` 和全部目标均为电机协议原始弧度。4号外部传动比不能在适配器中重复换算。上层若用关节角，应在已核实的映射层统一转换。

没有实测端点时 `calibrated` 必须为0，启动会被拒绝。标定后需同时提供抬起端点及可用原始位置范围；本模块不内置本台机械臂的抬起角度。

| 配置/检查 | 当前约束 |
| --- | --- |
| 规划速度 | 大于0且不超过0.12 rad/s，原始电机坐标 |
| 规划加速度、加加速度 | 分别不超过0.20 rad/s²、0.50 rad/s³ |
| 反馈速度上限 | 配置不得超过0.35 rad/s |
| 保持轴位置偏差 | 配置不得超过0.035 rad |
| 到位误差 | 配置不得超过0.03 rad |
| 到位确认 | 至少5帧，重复时间戳不累计 |
| 反馈时效 | 任一轴达到250ms未更新即退出 |
| 端点停留 | 500～5000ms |
| 单段超时 | 1000～120000ms，规划时至少额外留1秒到位确认时间 |

以上为软件允许配置的上界，不代表当前机构已完成该速度、角度或负载的实物验收。

停止、反馈丢失、故障、非有限值、超速、保持轴偏移或超时都会停止整组。正常完成或用户停止且STOP发送成功后，可显式重新启动；异常或STOP失败不会自动解锁。
