# LVGL屈肘循环演示 v7

## 本次功能

本次面向未穿戴、有机械支撑的iCAN实物演示。上电显示屈肘动作页面，初始不使能、不运动。触摸“启动”后，4、6号电机先采集并保持本轮位置，5号复用原工程已经验证的CSP接口与弯举规划器，先屈曲、再伸展，连续重复。完整往返后完成次数加一，不在每轮之间停止或重新使能。

触摸“停止”后退出循环，对5、4、6号分别发送STOP。正常停止且三轴STOP发送成功后，可以再次触摸“启动”，无需DAP授权或复位。重复启动点击不重置正在执行的动作，也不覆盖保持基线。空闲时先点停止，也可随后正常启动。

STOP会释放电机保持力，并非机械制动；现场应持续保留支撑。页面显示的是软件流程状态，不能替代现场确认静止。

## “约90°”的实际含义

用户要求展示此前完整屈肘动作，本次沿用已经实测运行的完整端点，不扩大机械行程。页面标注“约90°”：伸直参考原始值4.971363544rad，屈曲端6.439812851rad，原始差约84.14°；伸展返回目标5.021363544rad，保留原来的端点余量。这里不是重新确认的精密90°关节角标定。

5号沿用0.12rad/s指令速度、2A限流，4/6保持沿用1A限流。既有反馈新鲜度、故障检查、0.35rad/s反馈速度上限、保持轴位置偏移、分段超时与全部停止处理保留。仅在完整往返成功后续期45秒流程/42秒使能和55秒保持监督时限，卡住或缺帧不能通过刷新界面心跳延长时限。

## 双核分工与接口

- M55：`applications/ican_curl_panel.c`负责LVGL启动/停止按钮、当前状态和本轮完成次数，回调只发布请求，不阻塞等待CAN。
- M33：`applications/m33_bench5.c`独占三轴执行、采样、保持和停止；`bench5_guard.c`复用旧规划器连续循环。
- 公共结构：`firmware/shared/ican_curl_ui.h`，64字节，两条32字节缓存行分别由M55/M33写入，避免跨核缓存回写覆盖。
- 当前配套ABI11：UI邮箱0x240BD600，绑定描述符0x240BD640，网络诊断邮箱0x240BD660。重新链接后必须运行`tools/check_wifi_debug_binding.py`核对。
- 固件配置：`ican-lvgl-curl-j5-hold-j46-v7`。触屏启动无需Wi-Fi、NanoPi、ROS或DAP；原网络动作保留单次授权规则，不开放HTTP循环启动。

界面每200ms刷新心跳，运动中失去心跳1.5秒即退出并锁存故障。进入“设置”先请求停止并结束动作页面心跳；设置页的“动作”按钮可回到屈肘页面。其他代码删除动作页时也停止心跳。控制故障、STOP发送失败不允许继续启动，需检查后复位。上电、重启、仅刷新心跳、旧请求序号均不会自动启动。
