# iCAN 旧工程恢复版本：功能与验证说明

整理日期：2026-10-25（Asia/Shanghai）。源码来自本地 `xa-wearable-embodied-intelligence`，恢复功能基于原执行链路，最新安装记录为 `ican-lvgl-resistance-v14`，双核共享 ABI 为 11。本说明区分软件实现、历史设备记录和当前未验收事项。

## 本次保存的功能

### 固定动作与三轴保持

- 本地 LVGL 选择肘部屈伸、抬臂往返、旋转往返，以及约 30°小幅、约 60°中幅、屈肘停留变体。
- 肘部使用 5 号电机、4/6 号保持；抬臂使用 4 号、5/6 号保持；旋转使用 6 号、4/5 号保持。界面保留旧名称“前臂内旋”，实际解剖学命名应与机械结构核对。
- 从本轮静止采样位置建立相对起点，固定动作连续往返并返回本轮起点；停止后重新启动才重新采集起点。
- 保留旧规划器、平滑轨迹、限流、反馈检查和三轴 STOP 路径。协议范围不能代替实物行程验证。

### 三轴示教录制与回放

- 录制先停止三轴并检查停用反馈，再只读采集 4/5/6 号位置，不发送使能或运动目标。
- 最多保存 512 帧、仅一条 RAM 轨迹；新录制覆盖，复位或断电丢失。
- 三轴位置通过串行 CAN 事务读取，帧内跨度受限，不宣称硬件同步采样。
- 回放相对于本轮起点平移，三轴按同一段时间插值，必要时同步放慢；执行一次并停在轨迹终点，不自动回零。
- 缺帧、故障、越界、心跳失效及停止等进入整组停止流程。

### LVGL 本地交互

- 三页：固定动作、录制回放、阻力训练；大尺寸启动/停止，状态、帧数及进度提示。
- 运行期间翻页只切视图，不切换执行动作，持续心跳；离开到设置沿用停止处理。
- 本恢复基线使用本地触屏，关闭语音服务自启动；不以旧语音功能存在代表当前已启用。

### 肘部抗阻 v14

- 4/6 号保持本轮位置；5 号复用原速度阻尼策略，按速度方向输出反向电流，不生成屈伸位置轨迹。
- 增益 2 A/(原始 rad/s)，电流上限 1 A，速度死区 0.03 rad/s，20 ms 周期每步变化上限 0.03 A；换向清除旧符号电流。
- 准备时检查新停用反馈、静止采样，并预置和读回模式、限流及零电流后才使能。
- 单次最长 120 秒；反馈陈旧、故障、保持漂移、心跳丢失或人工停止均走三轴 STOP。
- 此恢复模式未启用自适应 PID/ADRC，无肌电依赖。停止会释放保持，机构仍需支撑。1 A 不是力矩或带载能力指标。

## 构建与运行限制

固件需要匹配的 Arm GCC、SCons、板级库和镜像打包环境。M55 的 `wifi_debug_binding.h` 必须与所配 M33 ELF 中的邮箱及 ABI 匹配；重链接 M33 后需重新核对，不直接沿用旧地址。

本次 Git 保存源码、配置、测试与功能说明，不附带本机临时固件镜像、RAM 转储、无线凭据或大批原始调试日志。新检出后需重新构建、打包并核对双核绑定；本提交不是直接可烧录的二进制发行包。

旧工程的肌电、视觉、ROS、App、平台和 VLA 基线继续保留；本次恢复不代表它们已与新版 SDK 或完整四轴模型统一，也不宣称助力、临床效果或完整自主取物已验收。
