# iCAN比赛演示恢复清单

## 当前候选版本

优先复用当前已实测的旧CSP控制入口、肘部规划器和三轴准备流程，不增加新的主控、ROS或肌电依赖。

LVGL目前有四种可启动配置：约90°往返、约30°往返、约60°往返、约60°端点停留2秒后返回。每种均为5号屈伸、4和6号保持启动位置，点击启动后连续循环，点击停止退出。以上是同一运动的不同幅度/驻留配置，不应宣传成四种不同关节运动。约90°沿用现有完整行程，实测约84°，不扩大目标凑整数。

原有完整屈伸及30°单次已有现场正常反馈；四种LVGL配置的连续循环仍需现场验收，不能用离线测试替代。

## 已完成验证

- 实际M33包装器回归：四种LVGL命令对应正确目标与驻留，分别连续三轮、停止、重新启动、准备中停止、心跳中断、反馈过期、保持轴漂移和故障锁存。
- M33、M55编译通过；链接器仍报告现有LOAD段RWX警告。
- 双核共享邮箱地址和ABI一致，中文字形覆盖检查通过。
- M33组合镜像与XIP校验镜像打包完成，哈希记录在 `firmware/m33/build/ican-original-manifest.json`。
- 本轮未烧录、复位或启动实物运动。

## 现场验收顺序

1. 托稳机构，关闭电机动力，保留USB和有线DAP，再更新配套双核固件。
2. 断动力确认屏幕菜单、空闲状态和无自动启动。
3. 确认支撑及行程后上电，先验收已跑通过的30°循环和STOP，再验收完整屈伸。
4. 再验收60°及停留模式，检查4、6号保持、循环次数、停止和再次启动。
5. 保留稳定可用镜像作为比赛回退版本。

## 后续功能取舍

抬臂入口保留未就绪提示。当前 `rehab_fixed_action.c` 中4号肩部前后动作配置是禁用状态且无端点，不能据此认定可直接恢复。该文件的旧5/6号固定绝对位置也与当前零位不同，不直接启用。

优先确认真正旧版本的抬臂/旋转调用与坐标映射，再做当前机构端点核对。肌电相关入口暂不恢复。录制回放放在固定动作稳定之后；现有ROS可选，不为新增上位机影响当前演示链路。
