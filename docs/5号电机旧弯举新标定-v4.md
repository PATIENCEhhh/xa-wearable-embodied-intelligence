> 后续开发：用户要求4、6号保持，5号弯举，已实现并烧录三轴版本，双核校验及断动力验收通过，见[三轴保持与肘部弯举-v5.md](三轴保持与肘部弯举-v5.md)。v5尚未实物运动验收；本文件保留单轴历史，不可用于描述v5的停止范围。

> 最新状态：先屈曲版本已进行一次上电试动，屈曲途中以超时结果退出并发送STOP，未完成往返。用户确认有屈曲，并更正异常现象为“前臂旋转”，不是上臂旋转。已暂停后续运动，要求托稳并关闭动力；关闭状态尚待明确确认。当前配置为`legacy-curl-j5-calibrated-v2`、邮箱ABI 5。下文更新完成时的空闲/断动力记录为历史状态，不能代替末节本次试动结果。

## 复用关系与本次变化

实际复用原工程弯举规划器计算目标、端点驻留、到位和故障，目标经原`control_motor_csp_setpoint()`下发。新增`rehab_curl_planner_start_flexion_first()`入口，并按起始运动阶段统计完整往返；原`rehab_curl_planner_start()`保留原有顺序。保留现有DAP一次性RAM授权和统一CAN出口，使旧ROS、其他关节及其他运动模式不能同时写电机。

使能前的准备仍由受限包装层执行：取得5对新位置/速度、检查范围与漂移、STOP及停用反馈、写入并读回模式/限流/限速/当前位置保持目标、再次核对位置，再启用主动状态报告并使能。这样不采用旧通用prepare函数“使能后才写参数”的顺序，也不在每次刷新目标时重新使能。

新入口调用`b5_start_curl()`，不再调用历史5°入口。旧5°状态机仍保留供离线回归，旧HTTP启动路径不再可用，不能把本版当作固定5°固件。旧规划器本来循环往返，本包装层在完成一轮后拦截下一轮目标并STOP；不自动循环、不自动回零。

两点姿态是手动参考，不是机械硬限位测量。软件包络在参考两端外扩0.01 rad，容纳参考采样及小姿态差；实际目标在两点参考内各缩0.05 rad（约2.86°）。原规划器允许在到位容差内转入驻留，因此不要求实物精确到目标小数位。

当前动作顺序固定为**先到高角度端（屈曲），停留500ms，再到低角度端（伸展），停留500ms并STOP，结束一轮**。屈曲端到位只算半轮，回到伸展端驻留后才算完整一轮；包装层在下一轮目标下发前结束。最终目标接近伸直，约为本次参考零点的2.86°，不是精确0°。实际方向、负载能力、跟随及STOP后姿态仍须现场验收。网络STOP不是独立硬件急停；停用电机会解除主动承载，须保留机械支撑。

原始位置目标先减新零偏并按方向/传动比转换成关节坐标，再传入旧CSP接口；接口内部转回原始位置，避免重复加零偏。永久电机编码器零点未写入。其他康复模式的历史配置不因本次更新自动成立；本版统一CAN出口仍仅允许5号专用线程动作，4/6仅查询和STOP。

## 接口与工具

服务标识`arm-wifi-debug-v4`，`motion_profile=legacy-curl-j5-calibrated-v2`，`single_cycle=true`。邮箱ABI更新为5、长度仍64字节，地址0x240BD620；描述符0x240BD600。已核对M33 ELF及M55绑定。旧动作配置v1或旧ABI工具不能授权当前固件。

| 接口 | 作用 |
|---|---|
| GET `/api/status` | 版本、固定动作配置标识、联网及双核状态，不返回令牌 |
| GET `/api/motor/{4,5,6}/{id,position,velocity,mode}` | 原始单位查询 |
| GET `/api/bench/5/status`、`/detail` | 动作状态、运行结果，以及起点/最后位置/当前目标 |
| POST `/api/bench/5/curl` | 本机DAP一次性授权后启动一轮旧弯举 |
| POST `/api/bench/5/stop` | 锁存STOP，禁止迟到请求再次启动 |
