# 肘部阻力训练

从触屏顶部选择第三页“阻力训练”。这一模式需要电机动力供电，4、6号保持本轮启动位置，5号根据手动屈伸速度提供反向阻力，不执行固定屈伸轨迹。

1. 机构保持未穿戴、有支撑，将手臂摆在原来的演示起点。
2. 打开电机动力，进入“阻力训练”，点击“启动训练”。
3. 显示“正在准备，请保持静止”时保持关节不动，等待准备完成。
4. 显示“手动屈伸，反向阻力训练”后，缓慢手动弯曲和伸展肘部。移动越快，阻力越大；静止时5号不输出主动电流，需要继续托稳前臂。
5. 点击红色“停止”结束；单次最多120秒。停止后4、5、6号均释放保持，请保留机械支撑。

阻力电流上限1A，速度死区0.03rad/s。1A不是力矩单位，也不代表保持轴能够承载任意负载。训练反馈速度上限1rad/s，动作窗口相对本轮起点为原始电机位置-0.15至+1.65rad，受协议位置范围约束；此窗口不能代替实物行程检查。

运行中可以翻页，正在执行的模式不会被切换；红色停止按钮在每一页都有效。固定动作和录制回放仍在前两页。故障退出后需检查现场再复位，不自动重复启动。

版本：ican-lvgl-resistance-v14。软件构建和主机回归已通过，实际阻力方向、手感和支撑效果仍需现场首次验收。
